GAMES

Text cultivation

A game where matter is Chinese characters. You write a character (water, fire, wood, metal) into the world and watch it burn, melt, or grow by the rules. Mountain, forest, and sword are not in the rules; I want players to recognize those themselves, which no real player has tested yet. It's at version 11, and I'm looking for playtesters.

Cozy Apocalypse AI Haven

A 3D post-apocalyptic survival building game in Godot. Days are for scavenging, dusk for repairs, night for campfire talks with the townsfolk. Opening, ending, and free management afterward are all coded, but a full playthrough hasn't been verified yet. Townsfolk each hold beliefs about the world; what they see shifts them, and the day's activity is scored and drawn from those beliefs.

SYSTEMS

Theseus

An AI collaboration system for my own use, started in March 2026. Agents write what happened into one append-only ledger, and long-term conclusions have to point back at the raw records. Each skill keeps one master copy, and any agent that needs it links to it. Routing requests to different models by difficulty existed once; it's archived now.

RESEARCH

One lane, two directions

A construction access road in the mountains has only one lane, so vehicles going opposite ways have to pass each other at passing bays (the formal name is long-distance single-lane two-way traffic). We use sensing and signal lights so that opposing convoys meet only at the bays. The system is already in use on an expressway construction site.

Since 2024

Emergence in lane changing

The question from my PhD. Every car changes lanes in whatever way is best for itself, and the whole road gets slower. Why, and how can that be corrected? Now I'm looking at how the rare but high-impact lane changes come about.

Since 2016

Passing the tests doesn't make the model right

Getting a large language model to turn a scheduling problem described in text into an optimization model, then checking whether the model is actually right. A program that passes the tests can still be wrong on a new set of numbers.
