通过测试，不等于建对了

让大模型把一段文字描述的调度问题建成优化模型，再检查它到底建对了没有。通过了测试的程序，换一批数字可能就错了。

TYPE

STATUS

WHEN

问题

调度问题（哪辆车先走，哪台设备干哪个活）一般要请懂运筹的人把它写成优化模型，变量是什么，约束有哪些，目标是什么，再交给求解器去算。现在可以让大模型读一段文字描述，直接把模型写出来。

麻烦在怎么知道它写对了。通常的办法是拿一组算例去测，答案和标准答案对上就算通过。可是对上只说明在这一组数上对了。比如模型漏了一条约束，这组数里那条约束正好不起作用，答案照样对，换一批数就错了（图 1）。
